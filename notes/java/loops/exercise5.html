Debugging & Code Comparison

1
Debug
What is the error in this code?
int i = 0; while (i < 5); { System.out.println(i); i++; }
Semicolon after the while condition
Missing curly braces
Wrong increment operator
No error
Explanation: The semicolon after while (i < 5); creates an infinite loop that does nothing. The curly braces block is separate and never executes. Remove the semicolon.
2
Compare
Which code is better for printing numbers 1 to 10?
Code A
for (int i = 1; i <= 10; i++) { System.out.println(i); }
Code B
int i = 1; while (i <= 10) { System.out.println(i); i++; }
Code A - for loop is more concise for counting
Code B - while loop is more readable
Both are equally good
Neither is correct
Explanation: Code A (for loop) is better because it keeps the counter variable, condition, and increment all in one line, making it more concise and reducing the chance of forgetting to increment.
3
Debug
Why does this loop never execute?
for (int i = 10; i < 5; i++) { System.out.println("Hello"); }
Initial value is greater than the limit
Missing semicolon
Wrong increment direction
Syntax error in print statement
Explanation: The initial value i = 10 is already greater than the condition i < 5, so the condition is false from the start. The loop body never executes.
4
Best Practice
Which loop is most appropriate for reading user input until they enter "quit"?
for loop
while loop
do-while loop
All are equally good
Explanation: A while loop (or do-while) is best when you don't know how many iterations will occur. For loops are better when you know the exact number of iterations. Since we don't know when the user will type "quit", while is most appropriate.
5
Debug
What's wrong with this code that should print even numbers from 0 to 10?
for (int i = 0; i <= 10; i++) { if (i % 2 = 0) { System.out.println(i); } }
Should use == instead of = in the if condition
Wrong loop range
Missing break statement
Should use i += 2 instead
Explanation: The = operator is for assignment, not comparison. Should use == for comparison. The code i % 2 = 0 tries to assign 0 to the result of i % 2, which causes a compilation error.
6
Compare
Which approach is more efficient for printing even numbers from 0 to 100?
Code A
for (int i = 0; i <= 100; i++) { if (i % 2 == 0) { System.out.println(i); } }
Code B
for (int i = 0; i <= 100; i += 2) { System.out.println(i); }
Code A - checks each number
Code B - directly iterates through even numbers
Both are equally efficient
Code A is more readable
Explanation: Code B is more efficient because it only iterates 51 times (0, 2, 4...100) instead of 101 times. It avoids the if condition check and skips odd numbers entirely.
7
Debug
Find the bug that prevents this code from stopping:
int count = 1; while (count <= 5) { System.out.println("Count: " + count); }
Missing increment - count never changes
Wrong condition operator
Wrong initial value
No error - code will stop
Explanation: The code is missing count++ or count = count + 1. Without incrementing count, it remains 1 forever, making the condition always true, resulting in an infinite loop.
8
Debug & Fix
Fix this code to correctly sum numbers from 1 to 10:
int sum = 0; for (int i = 1; i < 10; i++) { sum += i; } System.out.println("Sum: " + sum);
What should the condition be to include 10?
Correct condition: i
Explanation: The condition i < 10 stops at i = 9. To include 10, use i <= 10 or i < 11. The current code only sums 1+2+...+9 = 45, but should sum to 55.
9
Compare
Which loop guarantees at least one execution?
Code A
int x = 10; while (x < 5) { System.out.println(x); x++; }
Code B
int x = 10; do { System.out.println(x); x++; } while (x < 5);
Code A - while loop
Code B - do-while loop
Both execute at least once
Neither executes
Explanation: Code B (do-while) executes at least once because it checks the condition AFTER the first execution. Code A (while) checks the condition BEFORE executing, so it never runs when x = 10.
10
Debug
What will happen when this code runs?
for (int i = 0; i < 10; i--) { System.out.println(i); }
Infinite loop - i keeps decreasing
Prints 0 to 9
Prints 10 to 1
Compilation error
Explanation: This creates an infinite loop. i starts at 0 (which is < 10), prints 0, then decrements to -1 (still < 10), prints -1, and continues forever into negative numbers.
