Master the While Loop

1
Multiple Choice
What is the output of the following code?
int x = 5; while (x > 0) { System.out.print(x + " "); x--; }
5 4 3 2 1
5 4 3 2 1 0
4 3 2 1 0
Infinite loop
Explanation: The loop prints 5, 4, 3, 2, 1 and stops when x becomes 0 because the condition (x > 0) becomes false.
2
Multiple Choice
Which of the following while loops will execute at least once?
while (false) { System.out.println("Hello"); }
while (5 < 3) { System.out.println("Hello"); }
int x = 0; while (x > 0) { System.out.println("Hello"); }
None of the above
Explanation: All of these while loops have conditions that are false from the start, so none will execute even once. A do-while loop would execute at least once.

How many times will "Java" be printed?
int count = 10; while (count > 5) { System.out.println("Java"); count -= 2; }
2 times
3 times

Infinite loop
Explanation: The loop runs when count is 10, 8, and 6 (3 times total). When count becomes 4, the condition (count > 5) is false.
