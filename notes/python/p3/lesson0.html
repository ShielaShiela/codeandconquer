Basic Syntax 基本語法
Understanding Python's fundamental structure
▼
Indentation 縮排
Python uses indentation to define code blocks
if condition: # This is indented (4 spaces) print("Hello") print("World")
English: Python uses indentation (spaces/tabs) instead of braces {} to group statements.
繁體中文: Python 使用縮排（空格/制表符）而不是大括號來組織程式碼區塊。
Comments 註解
Adding explanatory text to your code
# This is a single-line comment 單行註解 print("Hello") # Comment after code 行末註解 """ This is a multi-line comment 多行註解 Used for documentation 用於文件說明 """
Rules 規則:
• Single-line: # symbol 單行註解用 # 符號
• Multi-line: """ or ''' 多行註解用三引號

Control Structures 控制結構
Making decisions and repeating actions
▼
Conditional Statements 條件陳述式
Making decisions in your program
# If-elif-else structure score = 85 if score >= 90: grade = "A" elif score >= 80: grade = "B" elif score >= 70: grade = "C" else: grade = "F" print(f"Your grade is: {grade}")
English: Use if/elif/else to make decisions based on conditions.
繁體中文: 使用 if/elif/else 根據條件做出決策。
Loops 迴圈
Repeating actions multiple times
# For loop 計數迴圈 for i in range(5): print(f"Count: {i}") # While loop 條件迴圈 count = 0 while count < 3: print(f"While loop: {count}") count += 1
Loop Types 迴圈類型:
• for: Known number of iterations 已知迭代次數
• while: Condition-based repetition 基於條件的重複
Functions 函數
Organizing code into reusable blocks
▼
Function Definition 函數定義
Creating reusable code blocks
# Function definition 函數定義 def calculate_area(length, width): """ Calculate the area of a rectangle 計算矩形面積 """ area = length * width return area # Function call 函數呼叫 result = calculate_area(5, 3) print(f"Area: {result}")
Function Structure 函數結構:
• def: keyword to define function 定義函數的關鍵字
• Parameters: input values 輸入參數
• return: output value 回傳值
• Docstring: function documentation 函數說明
🎯 Complete Example: Temperature Converter
def celsius_to_fahrenheit(celsius): """Convert Celsius to Fahrenheit 攝氏度轉華氏度""" fahrenheit = (celsius * 9/5) + 32 return fahrenheit def fahrenheit_to_celsius(fahrenheit): """Convert Fahrenheit to Celsius 華氏度轉攝氏度""" celsius = (fahrenheit - 32) * 5/9 return celsius # Usage examples 使用範例 temp_c = 25 temp_f = celsius_to_fahrenheit(temp_c) print(f"{temp_c}°C = {temp_f}°F") temp_f = 77 temp_c = fahrenheit_to_celsius(temp_f) print(f"{temp_f}°F = {temp_c:.1f}°C")

Naming Conventions 命名慣例
How to name variables and functions properly
# Good naming 好的命名 student_name = "Alice" # snake_case for variables total_score = 100 # descriptive names def calculate_average(scores): # function names return sum(scores) / len(scores) # Bad naming 不好的命名 # n = "Alice" # unclear # x = 100 # meaningless
Python Naming Rules Python命名規則:
• Variables: snake_case 變數使用底線命名
• Functions: snake_case 函數使用底線命名
• Constants: UPPER_CASE 常數使用大寫
• Classes: PascalCase 類別使用帕斯卡命名
Code Organization 程式碼組織
Structuring your Python programs
# Import statements at the top 匯入語句放在頂部 import math from datetime import datetime # Constants 常數定義 PI = 3.14159 MAX_STUDENTS = 30 # Function definitions 函數定義 def main(): """Main program logic 主程式邏輯""" print("Program started") # Program entry point 程式進入點 if __name__ == "__main__": main()
English: Organize code logically with imports, constants, functions, and main execution.
繁體中文: 邏輯性地組織程式碼，包括匯入、常數、函數和主程式執行。
