Python Functions: No Return Values & Global Variables

Python 函數：無返回值與全域變數

Introduction | 簡介

Functions in Python are reusable blocks of code that perform specific tasks.

（Python 中的函數是執行特定任務的可重複使用程式碼區塊。）

Not all functions need to return values - some functions perform actions without sending data back.

（並非所有函數都需要返回值 - 有些函數執行動作而不返回資料。）

Key Concept | 核心概念:
A function without a return statement returns None by default.
沒有 return 語句的函數預設返回 None。

Basic Function Structure (No Parameters, No Return) | 基本函數結構（無參數，無返回值）

Function Anatomy | 函數結構

def function_name():      ① Function Header
    # function body        ② Function Body
    statement1
    statement2
Parts Explanation | 部分說明:
  • ① Function Header | 函數標頭: def function_name():
    • def - keyword to define a function | 定義函數的關鍵字
    • function_name - name of the function | 函數名稱
    • () - parentheses (empty = no parameters) | 括號（空的 = 無參數）
    • : - colon marks the start of function body | 冒號標記函數主體的開始
  • ② Function Body | 函數主體: Indented code that executes when function is called | 呼叫函數時執行的縮排程式碼

Example 1: Simple Greeting Function | 範例 1：簡單的問候函數

# Define the function | 定義函數
def say_hello():
    print("Hello, World!")
    print("Welcome to Python functions!")

# Call the function | 呼叫函數
say_hello()
Output | 輸出:
Hello, World!
Welcome to Python functions!
Explanation | 說明:
This function prints messages but doesn't return any value. It performs an action (printing) and then completes.
此函數列印訊息但不返回任何值。它執行動作（列印）然後完成。

Global Variables | 全域變數

Global variables are created outside of functions and can be accessed anywhere in the program.

（全域變數在函數外部建立，可在程式的任何地方存取。）

Important | 重要:
To modify a global variable inside a function, you must use the global keyword.
要在函數內部修改全域變數，必須使用 global 關鍵字。

Example 2: Reading Global Variables | 範例 2：讀取全域變數

# Global variable | 全域變數
user_name = "Alice"

def greet_user():
    # Reading global variable (no 'global' keyword needed) | 讀取全域變數（不需要 'global' 關鍵字）
    print(f"Hello, {user_name}!")
    print("How are you today?")

greet_user()
Output | 輸出:
Hello, Alice!
How are you today?

Example 3: Modifying Global Variables | 範例 3：修改全域變數

# Global variable | 全域變數
counter = 0

def increment_counter():
    global counter  # Declare that we're using the global variable | 宣告我們正在使用全域變數
    counter = counter + 1
    print(f"Counter is now: {counter}")

print(f"Initial counter: {counter}")
increment_counter()
increment_counter()
increment_counter()
print(f"Final counter: {counter}")
Output | 輸出:
Initial counter: 0
Counter is now: 1
Counter is now: 2
Counter is now: 3
Final counter: 3

Example 4: Multiple Global Variables | 範例 4：多個全域變數

# Multiple global variables | 多個全域變數
score = 0
player_name = "Player1"
level = 1

def update_game_status():
    global score, level  # Multiple global variables | 多個全域變數
    score = score + 100
    level = level + 1
    print(f"{player_name} advanced to level {level}!")
    print(f"Current score: {score}")

update_game_status()
update_game_status()
Output | 輸出:
Player1 advanced to level 2!
Current score: 100
Player1 advanced to level 3!
Current score: 200

Example 5: Practical Example - Task Manager | 範例 5：實際範例 - 任務管理器

# Global variables for task management | 任務管理的全域變數
tasks = []
completed_count = 0

def add_task():
    global tasks
    task = "Complete homework"
    tasks.append(task)
    print(f"Added task: {task}")
    print(f"Total tasks: {len(tasks)}")

def complete_task():
    global tasks, completed_count
    if len(tasks) > 0:
        completed = tasks.pop(0)
        completed_count = completed_count + 1
        print(f"Completed: {completed}")
        print(f"Tasks completed today: {completed_count}")

def show_status():
    print(f"\n=== Task Status | 任務狀態 ===")
    print(f"Pending tasks: {len(tasks)}")
    print(f"Completed tasks: {completed_count}")

# Using the functions | 使用函數
add_task()
add_task()
show_status()
complete_task()
show_status()
Output | 輸出:
Added task: Complete homework
Total tasks: 1
Added task: Complete homework
Total tasks: 2

=== Task Status | 任務狀態 ===
Pending tasks: 2
Completed tasks: 0
Completed: Complete homework
Tasks completed today: 1

=== Task Status | 任務狀態 ===
Pending tasks: 1
Completed tasks: 1

Exercise 3: Write Your Own Function | 練習 3：編寫你自己的函數

Create a function based on the requirements below! | 根據以下要求建立一個函數！

Task | 任務

Requirements | 要求:

  • Create a global variable called balance with initial value 1000
  • 建立一個名為 balance 的全域變數，初始值為 1000
  • Create a function called withdraw_money with no parameters
  • 建立一個名為 withdraw_money 的函數，不帶參數
  • The function should subtract 100 from the balance
  • 函數應從餘額中減去 100
  • The function should print the new balance
  • 函數應列印新餘額
  • The function should NOT return any value
  • 函數不應返回任何值

Write your code here | 在這裡寫下你的程式碼:

✓ Sample Solution | 參考解答:

# Global variable | 全域變數
balance = 1000

def withdraw_money():
    global balance  # Declare global variable | 宣告全域變數
    balance = balance - 100  # Subtract 100 | 減去 100
    print(f"Current balance: ${balance}")  # Print new balance | 列印新餘額

# Test the function | 測試函數
print(f"Initial balance: ${balance}")
withdraw_money()
withdraw_money()
print(f"Final balance: ${balance}")
Expected Output | 預期輸出:
Initial balance: $1000
Current balance: $900
Current balance: $800
Final balance: $800

Key Takeaways | 重點總結

  • Functions without return perform actions but return None by default
    沒有返回值的函數執行動作但預設返回 None
  • Global variables are defined outside functions and accessible everywhere
    全域變數在函數外部定義，可在任何地方存取
  • Use the global keyword to modify global variables inside functions
    使用 global 關鍵字在函數內部修改全域變數
  • Reading global variables doesn't require the global keyword
    讀取全域變數不需要 global 關鍵字
  • Function structure: def name(): followed by indented code block
    函數結構：def 名稱(): 後接縮排的程式碼區塊
