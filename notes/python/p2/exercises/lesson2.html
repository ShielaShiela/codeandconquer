🧮 Question 1: Adding numbers together

🍦 Question 9: Another choice

🏠 Question 10: Inside another choice

🎯 How to Play

  • Read each story or problem carefully

  • Think about what symbol or word should go there
  • Type your answer in the box
  • Use the hints to help you!
  • Click "Check My Answers" when you're done
  • For math: + (plus), - (minus), * (times), > (bigger), < (smaller), == (equal)
